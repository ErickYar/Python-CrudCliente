#  Sistema CRUD de Clientes con Python y MySQL

Sistema de gestión de clientes por consola que permite Crear, Leer, Actualizar y Eliminar (CRUD) registros en una base de datos MySQL. Desarrollado con Programación Orientada a Objetos (POO) y buenas prácticas de seguridad.

##  Características

- **CRUD completo:** Registrar, listar, actualizar y eliminar clientes.
- **Conexión segura a MySQL:** Uso de variables de entorno (`.env`) para no exponer credenciales en el código.
- **Consultas parametrizadas:** Protección contra inyección SQL.
- **Programación Orientada a Objetos (POO):** Código organizado en clases y métodos reutilizables.
- **Manejo de errores:** Captura de excepciones para errores de conexión o consultas SQL.
- **Menú interactivo:** Interfaz por consola fácil de usar.

##  Tecnologías utilizadas

- Python 3.10+
- MySQL Server
- mysql-connector-python
- python-dotenv

##  Requisitos previos

- Tener Python instalado (versión 3.10 o superior).
- Tener MySQL Server instalado y corriendo localmente.
- Un cliente de MySQL (MySQL Workbench, DBeaver o la terminal) para ejecutar el script SQL.
